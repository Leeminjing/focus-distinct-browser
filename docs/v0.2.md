# v0.2 · Native Browser Shell

本版只升级原生浏览器外壳，保持 C++17、Win32、WebView2、独立数据目录、控制租约和 JSONL v1。没有增加调用接口，也没有改变调用方的对象映射。

## 可见变化

- 单行 64 DIP 工具栏，系统标题栏保留创建时的浏览器名称。工具栏比 v0.1 少占 48 DIP。
- 返回、前进、刷新 / 停止、原生地址输入；导航状态来自 WebView2 自己的事件和历史接口。
- 可自动控制、Agent 操作、接管中、人工控制、暂停、故障和断连都有明确文字；接管 / 交还按钮随状态变化。
- 系统明暗主题、高对比度颜色、DPI 字体与布局、焦点边框、原生可访问名称与提示；加载时只有底部细条反馈。
- 一个 EXE。Direct2D、DirectWrite、DWM 和 Common Controls 都是 Windows 组件；运行时依赖仍是系统 WebView2 Runtime。

## 人工导航与控制权

点击工具栏导航或进入地址输入时先撤销自动令牌。已经派发的点击、输入和截图先收尾；在途自动导航可停止并报告其真实结果，然后才执行用户提交的新地址或历史导航。交还以后仍然要取得新令牌并观察，旧令牌和旧观察不恢复。

直接点击网页、在网页中输入的自动仲裁仍属于下一阶段。工具栏没有伪装成 v0.3 的完整自动接管能力。

## 键盘

| 按键 | 行为 |
| --- | --- |
| Ctrl+L / Alt+D | 聚焦地址栏并全选 |
| Enter | 提交地址；无协议的域名默认补 HTTPS |
| Esc（地址栏） | 放弃编辑，恢复实际 URL 并回到网页 |
| Alt+Left / Alt+Right | 返回 / 前进 |
| Ctrl+R / F5 | 刷新 |
| Esc（页面加载中） | 停止 |
| Tab / Shift+Tab | 在可用原生控件间移动，边界返回网页 |

地址输入保留原生选择、粘贴和 IME 路径；IME 组合输入期间，确认候选词的 Enter 不会提前导航。

## 已执行的检查

构建与运行入口：`scripts/build.ps1`、`scripts/test.ps1`。所有测试都在 Windows 上运行，网页操作使用真实 WebView2。

- 原有状态机、11 组独立 / 并行 / 共享集成、4 组导航结算、协议与故障检查。
- 新外壳检查：地址输入、返回 / 前进 / 刷新、停止、登录数据等价的 Cookie / localStorage 保留、旧令牌失效、在途操作交接、64 DIP 网页边界、缩放无重叠、中文选择编辑和 IME 确认保护、快捷键消息处理、故障与断连可见。
- 复用生产 NativeToolbar 的独立原生组件宿主检查浅色 / 深色、96 / 144 DPI 和实际像素颜色；注册表重定向只在测试进程生效，不改用户系统主题。
- `PrintWindow` 只截取测试自己创建的 HWND，测试截图不读取其他应用或整个桌面。截图在 `artifacts/`；README 的截图来自真实宿主和真实测试网页。

## 验证限制

本机 Windows 拒绝后台进程激活到前台，返回 `foreground:false`。没有绕过系统策略或注入全局键盘事件；已验证地址控件消息、F5 消息循环及 Controller 转交后的 Ctrl+L / Ctrl+R / Alt+Left / Alt+Right 路径，物理组合键端到端仍需人工确认。

96 / 144 DPI 检查覆盖原生控件尺寸和渲染，不能代替两个不同 DPI 显示器之间的真实拖动。中文编辑和 IME 消息保护已测，候选窗、具体输入法版本和高对比度主题的完整人工体验也应在目标机器补验。

## 产物

提交源码后运行 `scripts/package.ps1`，生成单 EXE、SHA-256 清单和产物元数据。元数据只包含版本、平台、大小、摘要、源码提交、协议版本和 Runtime 要求，没有上层应用业务信息。测试专用的 `toolbar-component.exe` 不属于分发产物。
